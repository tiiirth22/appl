# ApplianceIQ Roadmap

This document outlines the planned features and improvements for the ApplianceIQ platform.

## Phase 1: Core Functionality (Completed)
- [x] Initial FastAPI server implementation.
- [x] React-based dashboard for administrators and business owners.
- [x] JWT-based authentication system.
- [x] Basic manual upload and storage.

## Phase 2: AI & RAG Integration (In Progress)
- [x] Document ingestion with text extraction (PDF and Image).
- [x] Vector store integration (Qdrant).
- [ ] RAG-based question answering using Llama 3.1.
- [ ] Multi-lingual support for manual processing.

## Phase 3: QR Code & Customer Access (Pending)
- [x] QR code generation for manuals.
- [ ] Publicly accessible chatbot interface for customers.
- [ ] Analytics dashboard for tracking customer queries and feedback.

## Phase 4: Production & Scale (Future)
- [ ] Containerization with Docker.
- [ ] Deployment to cloud providers (AWS/Azure/GCP).
- [ ] Performance optimization for high-traffic scenarios.
- [ ] Advanced user management and billing integration.
