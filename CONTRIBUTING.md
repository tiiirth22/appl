# Contributing to ApplianceIQ

We welcome contributions to ApplianceIQ! To ensure a smooth process, please follow these guidelines.

## Development Workflow

1. Fork the repository.
2. Create a new branch for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes and ensure they follow the project's coding standards.
4. Commit your changes with a descriptive commit message.
5. Push your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
6. Open a Pull Request against the main branch.

## Coding Standards

- Use clear and descriptive variable and function names.
- Ensure all new features are documented in the appropriate Markdown files.
- Follow the existing project structure and patterns.
- For the backend, use type hints where possible.
- For the frontend, prioritize accessibility and responsive design.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository. Provide as much detail as possible, including steps to reproduce the issue.
